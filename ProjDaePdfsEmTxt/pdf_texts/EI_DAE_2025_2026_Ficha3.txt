1. By default, an entity is mapped with a database table  of the same name (all lowercase) . 
However, we ’ll follow the convention where entities are named in singular (ex.: “ Student”, 
“Country”) and database tables are named in plural (ex.: “students”, “countries”). We can name 
set a different table name using the @Table class annotation:  
@Table(name = "students") 
From now on, you should do this for all entities. 
 
2. We may also want to define some validations to entities’ attributes at the entity level (not only 
at business logic and/or client applications/presentation logic layer level). For example, we do 
not want any attributes of entity Student to hold empty values.  
Annotate attributes username, password, name and email of entity Student with the 
@NotBlank annotation.  
Annotate attribute email with the @Email annotation so it’s validated as an e-mail. 
Update the @Table annotation to disable e-mail duplicates: 
@Table(name = "students",  
    uniqueConstraints = { @UniqueConstraint(columnNames = "email") }) 
NOTE: don’t forget to add the comma separator before uniqueConstrains.

6. Annotate the course attribute in the Student entity with the following annotations: 
@ManyToOne 
@NotNull 
The @ManyToOne annotation states that there is a many to one mapping between the Student 
entity and the Course entity. As this will be the “owner side” of the relationship,  no more 
configuration is required. The @NotNull annotation in this relationship states that a student 
must always belong to a course.  
 
7. Annotate the students attribute of the Course entity with the following annotation: 
@OneToMany(mappedBy = "course")  
This annotation states that there is a one to many relationship between the Course entity and 
the Student entity (“many students belong to one course” or, inversely, “one course has many 
students”). The mappedBy attribute is required  to make this the “referencing side” of the 
relationship (not the owner). Its value states the attribute name in the owner sid e (attribute 
course of the Student entity).
